# CABBAGE: настоящий исходный движок

Этот архив заменяет предыдущий CABBAGE-GitHub.zip.
Здесь CABBAGE запускает сам Investing Algorithm Framework: его стратегии,
риск-контроль, исполнение ордеров, базу данных, портфель и отчёты.
Исходный проект целиком сохранён, включая примеры, тесты и исторические данные.

## Windows

Установи Python 3.12, распакуй архив, открой папку cabbage.
Запусти SETUP-WINDOWS.bat и дождись завершения установки.

Затем из терминала в этой папке:

```powershell
.venv\Scripts\python -m cabbage doctor
.venv\Scripts\python -m cabbage backtest
```

Бэктест не требует ключей биржи или подключения к бирже после установки пакетов.
Отчёт: runtime/backtest/bitvavo/BTC-EUR/report.html.

Для котировок биржи и виртуального исполнения:

```powershell
.venv\Scripts\python -m cabbage doctor --online
.venv\Scripts\python -m cabbage paper --iterations 1
```

Без --iterations 1 процесс работает постоянно.

## Реальное исполнение

Скопируй .env.example в .env. Укажи рынок, пару и ключи своей биржи.
По умолчанию стоят BITVAVO / BTC/EUR — как в исходных примерах.
Сумма входа 50 EUR, стоп 5%, свечи 2 часа. Настройки меняются в .env.
Проверь доступность биржи для своего аккаунта, торговой пары и минимальный ордер.

Команда ниже включает реальное исполнение ордеров через исходный CCXT-движок:

```powershell
.venv\Scripts\python -m cabbage live
```

Она требует собственные действующие API-ключи и баланс на бирже. Ордер появится
только при выполнении условий стратегии; принудительной покупки при запуске нет.
Я не отправлял реальные ордера и не проверял твой биржевой аккаунт.
Проверки с реальными деньгами из этого архива не следуют.

Ключи не присылай в чат и не загружай на GitHub. .env исключён через .gitignore.
Файл .env.example загружать можно: в нём пустые поля ключей.

## Что за стратегия

RSI + EMA из присланного исходника. Для CABBAGE настроены покупка/выход в spot,
фиксированная сумма входа и стоп. Это не Jev и не стратегия слежения за кошельками.
В присланном исходнике нет готовых Jev / Robinhood Chain интеграций.
Запуск этого кода не начнёт торговать мемкоинами Robinhood Chain.

## GitHub

1. Создай пустой репозиторий cabbage и клонируй через GitHub Desktop.
2. Скопируй ВСЁ содержимое папки cabbage из архива в папку репозитория.
3. Сделай Commit и Push origin.

Не загружай сам ZIP вместо кода. Файлов много, поэтому используй GitHub Desktop
или Git. Папки .github и файл .gitignore тоже входят в проект.
Если уже загрузил предыдущую версию, новый архив содержит другой корень проекта:
убери старый engine и vendor после сохранения собственной копии, затем замени
содержимое репозитория новым. Не смешивай два движка.

Запуск в macOS/Linux: `sh setup.sh`, затем `.venv/bin/python -m cabbage doctor`.

Статус всех проверок указан в VALIDATION.md. Полная документация оригинального
фреймворка сохранена в docs, docusaurus и UPSTREAM-README.md.
